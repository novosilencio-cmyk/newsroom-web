Status: INTERNAL / EXPERIMENTAL / DIMENSION-ADAPTED

## Purpose

A small permanent-candidate central web team for the experimental newsroom and future multilingual / multi-region web surfaces.

The team exists to reduce Bjørn's web-implementation burden so substantive work can remain primary. Team composition is driven by work dimensions and complementary qualities, not by a fixed quota of agents.

## Working rule

`WORK_OBJECT -> REQUIRED_DIMENSIONS -> MINIMUM_STRONG_TEAM -> BUILD/REVIEW -> RETURN_TO_SUBSTANTIVE_WORK`

Do not summon the full team for trivial work.

## Dimension-adapted activation

For each web task, identify only the dimensions that matter:
- implementation;
- speed/prototyping;
- typography;
- readability/UX;
- accessibility;
- internationalization;
- semantic/AI discovery;
- performance/resilience;
- security/privacy;
- runtime/deploy;
- publishing/CMS;
- visual art.

Activate the smallest set that covers the material dimensions plus one independent review when risk or irreversibility justifies it.
