## Editorial object

Question:

> When an earlier representation becomes active again, how do human memory and memory-augmented AI distinguish the past from what is valid now?

The article deliberately does **not** claim biological identity between human memory and AI memory.

## Source and claim control

### Human memory / source monitoring

Supported:
- source monitoring concerns inference about where remembered information came from;
- reality monitoring distinguishes internally generated from externally perceived material;
- the source-monitoring framework describes memory source as inferred from perceptual, contextual and cognitive features rather than carried as a simple source label.

Public evidence:
- https://pmc.ncbi.nlm.nih.gov/articles/PMC10318245/
- https://pmc.ncbi.nlm.nih.gov/articles/PMC13418370/
- https://pmc.ncbi.nlm.nih.gov/articles/PMC5312673/

### Reactivation and transformation

Supported:
- content-sensitive neural activity can be re-expressed during remembering;
- perception and memory retrieval overlap, while systematic differences remain;
- reactivation can influence subsequent cognition.

Public evidence:
- https://pmc.ncbi.nlm.nih.gov/articles/PMC7688497/
- https://pmc.ncbi.nlm.nih.gov/articles/PMC6907733/

### AI-agent memory

Supported:
- memory-augmented LLM agents can show experience-following;
- similar retrieved experience can drive similar output;
- prior errors and misaligned old experiences can negatively influence later tasks;
- agent-memory evaluation must test how memory guides later action, not recall alone;
- reconstructive approaches explicitly challenge static retrieve-then-reason designs.

Public evidence:
- https://arxiv.org/abs/2505.16067
- https://arxiv.org/abs/2602.16313
- https://openreview.net/forum?id=YPoHy6lgKP

## Counter-reading and boundaries

The strongest tempting overclaim was:

> human nervous systems and AI memory do not distinguish experience from memory.

The article narrows this. Humans have source/reality-monitoring mechanisms, and neural representations of remembered and perceived material are systematically distinguishable in several respects. The supported parallel is narrower:

> both systems can allow a prior representation to influence present processing, so origin, context and current validity matter.

No claim is made that:
- AI has subjective episodic experience;
- an LLM memory store is biologically equivalent to a nervous system;
- human source-monitoring errors and AI experience-following share one mechanism.

## Six-stage Ariadne language review

### Helhetsinntrykk

The draft has one clear movement: practical AI-memory question → human source monitoring → reactivation → AI experience-following → reconstructive memory → design implication.

### Styrker

- strong reader question at the opening;
- precise boundary between analogy and equivalence;
- object before abstraction;
- uncertainty remains visible;
- no method theatre in the body;
- source links appear where the reader can continue.

### Stilprofil

Calm explanatory Norwegian with medium-length relational sentences, short emphasis used sparingly, and repeated returns to one governing question: where did this representation come from, and does it still apply?

### Konkrete svakheter

Early versions risked:
- turning a functional analogy into a biological identity claim;
- making “reactivation” sound like literal replay;
- treating AI retrieval as inherently memory-aware;
- overloading the reader with architecture vocabulary.

### Forbedringsgrep

- explicitly state that human source monitoring exists;
- distinguish reactivation from transformed retrieval;
- separate documented finding, analogy and unestablished claim in a reader box;
- use one comparison panel rather than many technical categories;
- close with the practical design consequence instead of a speculative consciousness claim.

### Revidert eksempelversjon

The final article is the revised example version.
