# newsroom-web

Public publishing repository for the Experimental Newsroom web platform.

This repository is intentionally public and should contain only material that is safe for public source exposure: published/public-facing site code, assets, articles, and documentation intended for readers or contributors.

Internal editorial work, drafts, investigations, candidate teams, calibration material, unpublished source indexes, and other newsroom working material belong in the private Experimental Newsroom workspace and must not be stored here.

Before material enters this repository, follow the [editorial production-safety standard](docs/editorial-production-safety.md). Continuous integration checks the repository's source and publication surfaces for unresolved internal editorial markers and blocks deployment when it finds one.
