## State correction

The service register is not merely received. It is in active use as a boundary and maturation object for the newsroom website and the relationship between capacity analysis, journalism and possible paid services.

The source register remains authoritative for the service descriptions and maturity states. This integration note records how Experimental Newsroom uses it; it does not replace the source.

## Separation of functions

- Capacity analysis develops and tests findings, mechanisms and service candidates.
- Daena is the provisional umbrella/root for possible services; the final institutional name is not fixed by this note.
- Experimental Newsroom is the independent editorial layer. It may develop a journalistic hypothesis from a mature finding only after its own source work, testing and editorial assessment.
- Paid work cannot purchase a finding, conclusion, omission or publication decision.
- Protected OOS methods and training capacity are not made public merely because a result or service description is public.

## Editorial intake path

`raw material -> capacity analysis -> cross-source control -> finding -> counter-test -> mature finding -> journalistic hypothesis -> independent journalistic investigation -> editorial decision`

Crossing from capacity analysis into journalism changes the working object. The analytical finding is source material, not a ready-made article or a compulsory conclusion.

## Delta handoff rule

The capacity-accounting workstream continues independently. It should not duplicate or direct the newsroom's present work with the register.

A new handoff is due only when at least one material delta exists:

- a genuinely new service candidate arises from a real case;
- evidence materially strengthens, weakens or falsifies an existing candidate;
- a candidate's maturity state changes;
- a correction changes provenance, method, boundary or conflict-of-interest handling;
- a finding becomes sufficiently mature to justify an independent journalistic hypothesis.

Every delta handoff should contain provenance, epistemic state, changed fields, supporting evidence, unresolved uncertainty and the newsroom's freedom to decline or investigate independently.
